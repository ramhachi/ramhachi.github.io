PROJECT 01

sim_overall

FSAE車両開発のための、総合シミュレーション・最適化プラットフォーム。

車両全体の設計と部品単位の設計を、同じ開発基盤で検討するためにゼロから構築しました。アーキテクチャとインターフェースを先に定義し、機能を継続的に追加・検証できる構造にしています。

  • 高自由度の車両シミュレータをゼロから開発
  • PINNによるタイヤデータフィッティングを実装
  • 3D梁CAEを開発し、フレーム解析時間を約36万分の1に短縮
  • サスペンション、ドライバモデルを自動最適化
Python · C++ · MATLAB · PINN · RL / MPC / PID GitHub ↗

PROJECT 02

CFD-SDF

トポロジーの変化を許容する、空力設計の自動最適化。

FSAEと鳥人間コンテストの空力設計を対象に、Signed Distance Field（SDF）を用いた最適化手法を開発しました。形状のトポロジーを固定しやすい従来手法の制約を越え、最適化の途中でも構造が変化できる形状表現を目指しています。

  • 任意形状を対象とした空力最適化
  • 最適化過程でのトポロジー変化を許容
  • 形状表現、CFD解析、探索処理を統合
  • FSAE・鳥人間コンテストへの応用を設計
OpenFOAM · SDF · topology optimization GitHub ↗

PROJECT 03

フライトデータロガー

飛行を理解するために、必要なデータを確実に残す。

2024年・2025年の鳥人間コンテストにおけるフライトを分析するためのデータロガーです。要件設定、ハードウェア、組み込みソフトウェアを一貫して担当し、軽量化と計測の確実性を両立しました。

  • 高度、姿勢、速度、GPS、湿度、大気圧を記録
  • RP2040のコア特性を使い、待ち時間を削減
  • 最低限の構成に絞り、軽量な実装を設計
  • 実フライトの失敗原因をデータから分析
RP2040 · sensors · embedded software · data analysis 詳細は面談時に紹介します
