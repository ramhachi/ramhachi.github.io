About me

機械を作り、コードを書き、現場で確かめる。

皆川草太です。機械・電気・ソフトウェアを横断し、複雑な課題を実現可能な形まで分解していくことを得意としています。

FSAEと鳥人間コンテストを通じて、車両運動、空力、組み込み、数値解析に取り組んできました。数式やシミュレーションだけで終えず、実装し、作り、測り、次の設計へ戻すところまでを一つの開発として扱います。

アーキテクチャを先に設計して技術的な難しさを整理し、関係者と条件をすり合わせながら、現場で使える形まで持っていくことが私の強みです。

PROJECT 01 / VEHICLE SYSTEMS

sim_overall

FSAE車両の全体設計と部品設計を、一つの基盤で最適化する。

高自由度車両シミュレータをゼロから構築。アーキテクチャとインターフェースを先に定義し、AIエージェントを含む実装手段を組み込みやすい構造にすることで、開発速度と拡張性を高めました。

  • PINNによるタイヤデータフィッティング
  • 3D梁CAEを開発し、解析時間を約36万分の1に短縮
  • サスペンションジオメトリの自動最適化
  • RL・MPC・PIDによるドライバモデルの最適化

PROJECT 02 / AERODYNAMICS

CFD-SDF

トポロジーの変化を許容する、空力形状の自動最適化。

FSAEと鳥人間コンテストの空力設計を対象に、Signed Distance Field（SDF）を用いた最適化手法を開発しました。従来手法で固定されやすかった形状トポロジーを、最適化の途中でも変化させられる表現へ置き換えています。

  • 任意形状を対象とした空力最適化
  • 最適化中のトポロジー変化を許容
  • SDF、CFD解析、探索処理を統合

OPENFOAM / SDF / TOPOLOGY OPTIMIZATION

PROJECT 03 / EMBEDDED SYSTEMS

Flight Data
Logger

フライトを理解するために、必要なデータを確実に残す。

2024年・2025年の鳥人間コンテストに向けて、要件設定、ハードウェア、組み込みソフトウェアを一貫して開発。RP2040のコア特性を利用して処理の待ち時間を減らし、軽量化のために必要十分な構成へ絞りました。

  • 高度・姿勢・速度・GPS・湿度・大気圧を取得
  • RP2040を活用した低待ち時間の処理設計
  • 実フライトデータから失敗原因を分析

RP2040 / SENSORS / FIRMWARE / DATA ANALYSIS
